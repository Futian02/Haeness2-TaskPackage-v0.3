## 2. 老师的精确合同
源：`upstream/04_接口文档/技术指标验证方法.md` 第(2)项与 `upstream/README.md`第八部分。
- 抽样不少于50，记录随机脚本/种子和clause_id，**审核人不同于抽取人**。
- 逐条对PDF核条款号与页码、`content_raw`逐字一致、`applicable_conditions`不超出原文。
- 50条失败≤2为达标（至少48/50，即96%）；3条失败94%不达标，返工并重抽。
- 真实审核人的身份、复核意见、时间和签名须有独立可查证据；模型视觉候选、OCR、复测脚本/数字台账都不能冒用人工审核。
- 审核结论与**源 JSONL SHA、PDF SHA、页索引、审核时点**绑定。候选源发生变化需要重新判定已审核签名适用性。
