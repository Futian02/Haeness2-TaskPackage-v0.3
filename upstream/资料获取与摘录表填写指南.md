# 第二部分 · 摘录表怎么填(给学生)

## 2.1 为什么先填摘录表,不直接写 JSON

直接对着几百页的标准写 JSON,会有三个问题:抽哪些条款没标准、字段填错了发现不了、五个人格式各不相同。

摘录表是中间步骤:**先用表格把条款梳理清楚,确认无误后再由脚本批量转成 JSON。**

## 2.2 损伤机理摘录表字段

文件:`02_损伤机理参考/条款摘录表_损伤机理.xlsx`,只在「摘录表」页填,「填写示例」页有一行示范。

| 列名 | 填什么 | 示例 | 注意 |
|---|---|---|---|
| clause_id | 标准号去斜杠和空格+年份+条款号 | GBT30579-2022-6.7 | **主键,不能重复**;一个条款拆多行时加 -a/-b/-c |
| standard_code | 标准号 | GB/T 30579-2022 | 下拉选择 |
| clause_no | 条款号 | 6.7 | 本列是文本格式,别改成数字,否则 5.10 会变成 5.1 |
| page | 条款起始页 | 51 | 标准正文印刷页码,不是 PDF 阅读器的页码 |
| title | 损伤模式名称 | 湿硫化氢破坏 | 和 GB/T 30579-2022 附录A 索引里该条的名称一字不差,convert.py 会核对 |
| 原文摘录 | 标准原文,≤300字 | | **不许润色改写**;跨子条款摘录时每段前写子条款号,省略处用……;OCR 录入的要逐字校对 |
| 损伤描述及机理 | 怎么发生的 | | 八段式之一 |
| 损伤形态 | 分号分隔 | 氢鼓泡;氢致开裂 | 八段式之二 |
| 受影响的材料 | 分号分隔 | 碳钢;低合金钢 | 八段式之三,**保留原文写法,不受枚举表限制** |
| 主要影响因素 | 分号分隔 | pH值;硫化氢分压;温度 | 八段式之四 |
| 易发生部位 | 分号分隔 | 常减压装置酸性水系统 | 八段式之五,对应「易发生的装置或设备」 |
| 主要预防措施 | 分号分隔 | 选用抗氢致开裂钢;控制焊缝硬度 | 八段式之六 |
| 检测监测方法 | 分号分隔 | 湿荧光磁粉;超声检测 | 八段式之七 |
| 相关或伴随损伤 | 分号分隔 | 氢脆;胺应力腐蚀开裂 | 八段式之八,用标准原文的损伤模式名称 |
| 适用材质 | 从枚举值选 | 碳钢;低合金钢 | **不许自造词**;原文材料超出枚举的写进「其他适用条件」 |
| 适用介质 | 从枚举值选 | 湿硫化氢 | 同上 |
| 温度下限/上限 | 数字,无则留空 | (空) / 150 | 单位 ℃ |
| 压力下限/上限 | 数字,无则留空 | | 单位 MPa |
| 适用设备类型 | 从枚举值选 | 塔;换热器;管道 | |
| 其他适用条件 | 自由文本 | pH<4.5或存在氰化物时风险升高 | |
| 抽取人 | 学号_姓名 | | |
| 复核人 | 学号_姓名 | | 交叉核对后填,未复核留空 |
| 备注 | 存疑的地方写这里 | | **不确定就写,别猜** |

**八段式的来源**:GB/T 30579-2022 第 4.4 条规定每个损伤模式从八个方面描述,每个损伤模式条款下都有对应的八个子条款(例如盐酸腐蚀的 5.1.1~5.1.8)。填表时对着子条款逐段抽。团队另一条线的数据用同一套字段,所以**列名一个字都不能改**。

**受影响的材料 和 适用材质 的区别**:前者照抄原文,给 `affected_materials` 用;后者只写枚举表能表达的规范值,给工具做匹配用。例如氯化铵腐蚀的受影响材料里有蒙乃尔合金400、哈氏合金C276,「受影响的材料」列照写,「适用材质」列只写碳钢、低合金钢、300系列不锈钢、双相不锈钢,其余材料在「其他适用条件」里注明。

**牌号和类别怎么匹配**:摘录时按原文写,原文写类别就填类别,写牌号就填牌号。工具查询时入参可能是牌号,由 `04_接口文档/material_family.json` 把牌号向上展开成所属类别再去匹配,摘录的人不用管这一步。

## 2.3 RBI 摘录表字段

文件:`01_RBI标准/条款摘录表_RBI.xlsx`

前六列(clause_id 到 原文摘录)与上表相同,后面换成:

| 列名 | 填什么 | 示例 |
|---|---|---|
| 失效可能性等级 | 原文的分级值 | 3 |
| 失效后果等级 | 原文的分级值 | D |
| 风险等级(原始) | 标准自己的表述 | 中高风险 |
| 风险等级(统一) | 查映射表填,下拉选择 | L3 |
| 检验周期(年) | 数字;条款没给就留空 | |
| 推荐检验方法 | 分号分隔 | 定点测厚;超声扫查 |
| 适用条件各列 | 同机理表 | |
| 抽取人/复核人/备注 | 同机理表 | |

**风险等级(统一)** 必须查 `04_接口文档/risk_level_mapping.xlsx` 填写,不许自己判断。不同标准的分级体系不一样,不统一就没法合并。GB/T 26610.3-2014 的矩阵条款按可能性和后果查表;其他 GB/T 26610 部分按原文用语(低风险、中风险、中高风险、高风险)查表,用语不在表里的统一等级留空、在备注写明原文用语。`convert.py` 会自动核对,填错会报错,留空且能查到的会自动补上。

**RBI 条款怎么拆行**:GB/T 26610 的很多条款是赋值表或矩阵,不是一句话结论。表里每一行、矩阵里每一格拆成一条记录,用 -a/-b/-c 区分。例如 GB/T 26610.3-2014 第7章图1 风险矩阵共 25 格,按可能性1A、1B……5E 的顺序拆成 GBT26610.3-2014-7-a 到 -y;表1 失效可能性因子分级拆成5行。条款没给的字段(比如 26610.3 不给检验周期)就留空,不要从别处推。

## 2.4 填表五条纪律

1. **原文摘录不许改写。** 你觉得原文啰嗦也照抄,这一列是后面核对准确率的依据。
2. **枚举值只能从 enums.json 里选。** "碳钢"和"低碳钢"混用会让工具匹配失败。适用材质、介质、设备类型一格要填多个值,Excel 下拉框做不了多选,所以这几列没有下拉框:从「枚举值」页复制规范值,用分号隔开。`convert.py` 会逐个核对,写成别名会自动改成规范值并提示,写了枚举外的词直接报错。
3. **抽不动就跳过。** 有些条款是纯定义或纯管理要求,没有可结构化的判据,跳过即可。**宁可少 50 条,不许编 1 条。**
4. **存疑写备注,不要猜。** 备注里写清楚疑问点,每周五统一过一遍。
5. **一条条款一行。** 一个条款里如果讲了三种机理,拆成三行,clause_id 后加 -a/-b/-c 区分。

# 第三部分 · 从摘录表到 JSON

摘录表填完并通过每周五的检查后,在任务包根目录运行:

```
python 04_接口文档/convert.py          # 两份摘录表 → 05_提交区/clauses.jsonl
python 04_接口文档/validate.py         # 自查
```

`convert.py` 已写好,依赖 `pip install openpyxl`。它会先检查表头、必填列、clause_id 拼法、主键重复、原文字数、枚举值、风险等级映射和常见的错误叫法,有任何错误就不写出文件,并指出是哪个文件第几行。**不要手写 JSON**,手写必然出格式错。

报错一律回到 xlsx 里改,不要直接改 jsonl,否则下次转换又被覆盖。

**PDF 复制出乱码**:网盘里多数 GB/T 的 PDF 用了特殊字体编码,直接复制是乱码。原文摘录可以用 OCR(WPS、PaddleOCR 等)辅助录入,但必须逐字对照 PDF 校对,OCR 错字按改写原文处理。
